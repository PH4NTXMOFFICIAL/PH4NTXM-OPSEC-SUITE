# [ OPSEC NETWORK ]

## [ OVERVIEW ]

Inspects IPv4/IPv6 routes, configured DNS resolvers, active sockets, and network namespace state.

## [ USAGE ]

```bash
ph4ntxm-opsec-net
```

## [ RUNTIME ]

Reports findings and a session score using PH4NTXM network assumptions. Restricted visibility or missing utilities can limit the report.
The optional Lockdown action opens the PH4NTXM control dialog. It requires the separately installed PH4NTXM Lockdown stack; the suite alone does not provide a firewall.
